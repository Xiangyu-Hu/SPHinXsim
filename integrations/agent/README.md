# External agents

Agent support uses the native `sphinxsim` package and CLI. There is no separate
Agent installation or executable. See the maintained [native CLI and agent
workflow guide](../../docs/agent-workflows.md) for configuration authority,
CadQuery, frozen jobs, native desktop operations and tests.

- [MCP client setup](MCP_GUIDE.md)
- [Agent decision guide](AGENT_GUIDE.md)
- [Optional companion skill](skills/sphinxsim/SKILL.md)

Container images, remote desktop streaming, GPU runtime setup and host-specific
input drivers are independently maintained by deployment owners.
